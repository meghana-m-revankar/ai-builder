# ai-builder

Storage for the n8n AI Coding Agent.

| Folder | What it holds |
|---|---|
| `knowledge/` | Rules every AI agent follows (design and coding standards). Edit these files to change how projects are generated. |
| `projects/` | Generated projects, one folder each, committed by the n8n workflow. |

Static preview sites are published with GitHub Pages at
`https://meghana-m-revankar.github.io/ai-builder/projects/<project-name>/site/`
