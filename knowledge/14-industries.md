# 14 Industries

Pick the industry that matches the brief, then use its pages, sections, design approach and facts list. If none fits, use **Custom** at the end. Never mix two industries' page plans.

Each industry lists:
- **Pages**: the default page plan (use the brief's pages instead when given).
- **Home sections**: in order. `[3D]` = recommended 3D candidate, `[3D?]` = optional 3D, everything else is always 2D. See 15 Hero, Sections and 3D.
- **Design approach**: the look to aim for. Pick the matching theme in 17 Themes.
- **Facts to use**: the real facts this business needs. If missing, show them as Sample (00 Start Here).
- **Primary button**: the header and hero call to action.

---

## 1. Hosting & Technology
Subcategories: web hosting / cloud, SaaS product, IT services / MSP, mobile app product, AI / data, cybersecurity.
- **Pages**: Home, Features (or Services), Pricing, About, Blog, Contact (+ Login / Dashboard for apps).
- **Home sections**: Hero [3D] (product mockup, floating UI chips) → logo cloud → bento features → how it works → stats [3D?] → pricing (3 tiers, middle highlighted, monthly/yearly toggle) → comparison table → testimonials → FAQ → CTA.
- **Design approach**: crisp and technical. Dark hero or light hero with deep gradient glow, product screenshots built in HTML/CSS, code or terminal snippets, monospace numbers.
- **Facts to use**: plans and prices, main features, uptime / SLA, data-centre regions, integrations, support hours.
- **Primary button**: "Start free trial" / "See plans" / "Book a demo".
- **User flow**: Home → Features → Pricing (compare plans) → Sign up / Book demo. Every page ends with a pricing or demo CTA.

## 2. E-commerce & Online Stores
Subcategories: fashion & apparel, beauty & personal care, home & living, electronics, handmade / crafts, physical retail shop.
- **Pages**: Home, Shop (all products with filters), Product detail, Cart / Checkout, About, FAQ / Shipping, Contact.
- **Home sections**: Hero / product showcase [3D] → shop by category (image tiles) → best sellers grid → featured product split [3D?] → brand promise (shipping, returns, secure payment icons) → reviews → newsletter → CTA.
- **Design approach**: product-first. Big product photography on soft backgrounds, clean 2/3/4-column grids, strong "Add to cart" buttons, price always visible, trust badges near the button.
- **Facts to use**: products, prices, sizes/variants, shipping zones and cost, return policy, payment methods.
- **Primary button**: "Shop now".
- **User flow**: Home → Category / Shop (filter) → Product detail (variants, add to cart) → Cart → Checkout (details → delivery → summary) → Confirmation. Cart icon with count visible on every page.
- **Rules**: cart works with `localStorage`; checkout is a clear 3-step form (details → delivery → payment summary) with no fake payment; say "Payment integration added at launch".

## 3. Real Estate & Property
Subcategories: residential sales, rentals, commercial property, developer projects, property management.
- **Pages**: Home, Properties (listings with filters), Property detail, About / Agents, Contact.
- **Home sections**: Hero / property walkthrough [3D] (or full-bleed photo with search bar) → search & filters (location, type, budget, bedrooms) → featured listings → why us → gallery [3D?] → agents → testimonials → enquiry form.
- **Design approach**: premium and calm. Full-bleed architecture photography, generous white space, serif or elegant display headings, property cards with key facts (price, beds, baths, area) as icon rows, map section.
- **Facts to use**: listings or projects, locations, price ranges, licence / RERA number, agent names and phone.
- **Primary button**: "Book a viewing" / "Enquire now".
- **User flow**: Home (search) → Listings (filter, sort) → Property detail (gallery, facts, map, agent) → Enquiry / Book viewing form. Search bar reachable from every page.

## 4. Restaurants, Cafes & Hospitality
Subcategories: restaurant, cafe / coffee shop, bakery / desserts, cloud kitchen, hotel / resort, catering / events.
- **Pages**: Home, Menu (or Rooms), About, Gallery, Booking / Reservations, Contact.
- **Home sections**: Hero (full-bleed food or interior photo, 2D) → signature dishes → about / story split → menu highlights with category tabs → gallery [3D?] → reviews → booking form → location & hours.
- **Design approach**: warm and appetising. Editorial photography, cream or dark-moody backgrounds, elegant display type, menu cards with dish photo, description and price.
- **Facts to use**: menu with prices, opening hours, address and map, booking / delivery links, dietary labels (veg, vegan, spicy).
- **Primary button**: "Book a table" / "Order online" / "Check availability" (hotels).
- **User flow**: Home → Menu (or Rooms) → Booking (date, time/nights, guests) → Confirmation; or Menu → Order online link. Phone, hours and directions one tap away on mobile.
- **Rules**: when the AI picks the mode for each section, the hero stays 2D because food photography sells better. If the owner chooses 3D Interactive for the whole site, the hero may use a light 3D scene (e.g. a floating dish on a plinth) layered behind the photo.

## 5. Corporate, Agencies & Professional Services
Subcategories: marketing / creative agency, consulting, law firm, accounting / finance, manufacturing / industrial, logistics.
- **Pages**: Home, Services, Work / Case studies, About / Team, Insights (blog), Contact.
- **Home sections**: Hero [3D] (agencies) or strong typographic hero (law, finance) → client logos → services → featured case studies [3D?] → process → stats [3D?] → team → testimonials → CTA.
- **Design approach**: confident and structured. Big typography, clear grid, case-study cards with result numbers, credibility (certifications, years, clients) up front. Law and finance: navy/charcoal, restrained, no playful motion.
- **Facts to use**: services, clients and results, team and qualifications, certifications / registration, office address.
- **Primary button**: "Get a quote" / "Book a consultation" / "Start a project".
- **User flow**: Home → Services → Case study (proof) → Contact / Quote form (service, budget, timeline). Credibility (logos, results) before every CTA.

## Custom category
When the business does not fit the five above:
1. Name the business type in one phrase from the brief (e.g. "pet grooming", "wedding photographer").
2. **Pages**: Home, About, Services (or the main offering, named for the business), Gallery (if visual), Contact.
3. **Home sections**: Hero → trust strip → services → how it works → gallery [3D?] → testimonials (Sample if not given) → FAQ → CTA.
4. **Design approach**: choose the theme in 17 Themes whose mood matches the brief's words.
5. Ask for (or show as Sample) the 3-4 facts a customer of that business needs before buying.

## Existing website (redesign / improve / migrate / rebuild)
When the brief includes an existing website:
- **Keep** all its pages, real content, contact details, brand colours and logo unless the owner asked to change them.
- **Never remove** a page, feature or form. Put new suggestions in `summary` under "Suggested improvements".
- Redesign = same content, new design. Improve = same design language, fix usability/speed/SEO. Migrate = same site, new stack. Rebuild = new structure, but all real content carried over.
