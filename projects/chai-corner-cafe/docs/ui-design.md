# UI Design: Chai Corner Café

## Design System
- **Brand Palette**: Based on warm terracotta and chai brown.
  - `--brand-900`: #5D3A25 (Deep Chai Brown)
  - `--brand-700`: #A0522D (Terracotta)
  - `--brand-500`: #D2691E (Warm Spice)
  - `--brand-100`: #FDF5E6 (Cream)
  - `--accent-500`: #E8A33D (Golden Saffron)
- **Typography**: Plus Jakarta Sans (headings), Inter (body).
- **Icons**: Phosphor Icons (Regular).

## Layout Patterns
- **Marketing**: Sticky navbar, hero with warm gradient, bento grid for features, product showcase with category filters, FAQ accordion, footer with image credits.
- **Components**: Rounded cards (12px), pill buttons, soft shadows.
