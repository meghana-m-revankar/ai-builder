# Brew & Bean Cafe

A premium, neighborhood cafe website featuring a warm aesthetic with rich brown and cream tones.

## Pages
- Home (index.html): Full hero, features, featured drinks, stats, how-it-works, testimonials, FAQ, CTA.
- Menu (menu.html): Categorized product grid.
- About (about.html): Cafe story and team showcase.
- Contact (contact.html): Contact form and location details.
- Dashboard (dashboard.html): Staff overview with KPIs, activity tracking and charts.

## Setup
1. Open any .html file in a web browser.
2. Ensure you have internet access for the CDN-hosted Tailwind and Lucide icons.
