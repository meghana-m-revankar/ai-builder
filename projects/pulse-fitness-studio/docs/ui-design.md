# UI Design - Pulse Fitness Studio

## 1. Landing Page (Home)
- **Purpose**: Brand introduction, value proposition, CTA for trial booking.
- **Layout**: Hero section, Bento grid for features, "Class Highlights" (using data), CTA band.
- **Actions**: "Book Free Trial" (nav to booking), "View Schedule".

## 2. Class Schedule Page
- **Purpose**: Display available fitness sessions.
- **Layout**: Filter bar (by trainer/type), Calendar view or list view of cards.
- **Fields**: Class name, Time, Trainer, Status (Available/Full).
- **Actions**: "Book Now" (nav to booking).

## 3. Booking Form
- **Purpose**: Capture lead data for a free trial.
- **Layout**: Two-column responsive form.
- **Fields**: Name, Phone, Email, Preferred Date, Class Select (dropdown).
- **Actions**: "Confirm Booking" (Submit).

## 4. Admin Dashboard
- **Purpose**: Manage classes and trainers.
- **Layout**: Sidebar navigation, Stats cards, Data table with CRUD operations.
- **Actions**: Add Class, Edit Schedule, Delete Booking.
