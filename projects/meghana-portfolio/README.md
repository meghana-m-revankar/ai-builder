# MeghanaPortfolio

A professional portfolio backend API built with .NET 8, Clean Architecture, and EF Core.

## Prerequisites
- .NET SDK 8.0.100
- PostgreSQL

## How to run
1. Restore packages: `dotnet restore`
2. Update connection string in `src/MeghanaPortfolio.Api/appsettings.Development.json`
3. Run API: `cd src/MeghanaPortfolio.Api && dotnet run`

## Tests
`dotnet test`
