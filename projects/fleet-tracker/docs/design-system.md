# 01 Design System

## Typography
- Headings/UI: **Plus Jakarta Sans** (weights 500, 600, 700, 800).
- Body: **Inter** (weights 400, 500, 600).
- Numbers/IDs: **JetBrains Mono** (400, 500).

## Colours
- Brand-900: #0B1B3F, Brand-700: #1E3A8A, Brand-500: #3B5BDB, Brand-100: #E7ECFB.
- Accent-500: #F97316 (Primary CTA).
- Surface: #FFFFFF, Canvas: #F6F7FB.
- Ink-900: #0F172A, Ink-600: #475569.

## Layout (Dashboard)
- Fixed left sidebar (240px) with logo, navigation, user card.
- Top bar with notifications, profile dropdown.
- KPI cards in a 4-column row.
- `table-responsive` for data tables.
