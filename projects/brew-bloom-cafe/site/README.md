# Brew & Bloom Cafe

A high-end, premium specialty coffee shop and boutique florist located in the heart of Indiranagar, Bangalore.

## Project Structure
- `index.html`: The home landing page.
- `menu.html`: The full product and menu catalog.
- `contact.html`: Reservation form and location details.
- `dashboard.html`: Internal staff dashboard.
- `css/style.css`: Custom design tokens and helper classes.
- `js/tailwind.config.js`: Project-specific color palette and fonts.
- `js/data.js`: Mock data for the dashboard.
- `js/main.js`: Interactivity logic.

## Usage
1. Open any `.html` file in your browser.
2. Ensure you have internet access for CDN-hosted assets.
