# UI Design: QuickFix Home Services

## Design System
- **Brand Palette**: Based on a professional "Service Blue" and "Trust Green".
  - brand-700: #0284C7 (Sky Blue)
  - brand-900: #0C4A6E (Deep Navy)
  - brand-500: #38BDF8 (Light Blue)
  - brand-100: #E0F2FE (Soft Background)
  - accent-500: #16A34A (Success Green for status/actions)
- **Typography**: Plus Jakarta Sans (headings), Inter (body).
- **Icons**: Phosphor (Regular).

## Layout
- **Marketing**: Sticky navbar, hero with service search, feature grid, testimonial band, CTA footer.
- **Dashboard**: Fixed left sidebar (240px) with logo, navigation links, and user profile. Top bar with search and notifications. Main content area with KPI cards and data tables.

## Components
- **KPI Cards**: Icon, label, value, trend indicator.
- **Status Badges**: Soft background pills for booking status (Pending, Assigned, Completed).
- **Tables**: Zebra-striped rows, action dropdowns for assignment and status updates.
