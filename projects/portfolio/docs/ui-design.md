# UI Design - Meghana M Revankar Portfolio

## Overview
A high-end, modern single-page portfolio for a Senior Front-End Developer. The design emphasizes whitespace, bold typography, and a refined "bento-grid" aesthetic for project showcases.

## Layout & Design Tokens
- **Typography**: Plus Jakarta Sans (Headings), Inter (Body), JetBrains Mono (Codes).
- **Spacing**: Generous, using 4px-8px scale with 96px sections.
- **Color Palette**: 
  - Brand 700: #1E3A8A (Indigo)
  - Canvas: #F6F7FB (Light), #0B1B3F (Dark)
  - Accent: #F97316 (Orange)
- **Theme**: Dark/Light mode persistent toggle.

## Sections (index.html)
1. **Header/Navbar**: Sticky glassmorphism blur. Logo (text-wordmark), nav links, theme toggle, and CTA button.
2. **Hero**: Hero Title "Crafting Digital Experiences", Lead text, Two call-to-actions, and an abstract CSS workspace illustration.
3. **About**: Two-column layout on desktop. Left: Personal image. Right: Professional bio, key highlights, resume download.
4. **Projects**: Bento grid featuring 3 cards (Shopping Site, Analytics Dashboard, Mobile Landing). Each card includes a project image, tech stack tags, and a view link.
5. **Skills**: Floating chip grid with icons and skill names.
6. **Contact**: Form section with labeled inputs, validation styling, and a post-submission success message.
7. **Footer**: Rich footer with social links, copyright, and subtle link columns.
