# Green Valley Public School - Website

Welcome to the repository for **Green Valley Public School**, a premier CBSE-affiliated K-12 school in Mysuru, Karnataka.

## Prerequisites
- Any modern web browser (Chrome, Firefox, Safari, Edge)
- A local static file server (optional, for development, e.g., VS Code Live Server or `python3 -m http.server`)

## How to Run
1. Clone or download the repository.
2. Open the project folder.
3. Open `index.html` directly in your browser, or run a local server:
   ```bash
   python3 -m http.server 8000
   ```
4. Navigate to `http://localhost:8000` in your web browser.

## Pages Included
- **Home (`index.html`)**: Hero banner, key statistics, leadership welcome, highlights, upcoming events, and parent testimonials.
- **About Us (`about.html`)**: School history, vision/mission, and leadership team profiles (Principal Dr. Lakshmi Prasad, Vice Principal Ramesh Gowda, Head of Science Ananya Shetty, Sports Director Farhan Ali).
- **Academics (`academics.html`)**: Curriculum overview from Nursery to Class 12, Science & Commerce streams, and sample class timetable.
- **Admissions (`admissions.html`)**: Admission process, comprehensive fee structure table, and interactive admission enquiry form.
- **Facilities (`facilities.html`)**: Campus facilities gallery including smart classrooms, science labs, library, sports ground, and school transport.
- **Contact Us (`contact.html`)**: School address, phone number, email, office hours, contact form, and Google map embed.

## Tech Stack
- HTML5
- Tailwind CSS (via CDN)
- Vanilla JavaScript
