# QuickBill POS

This is a browser-based, offline-first Point of Sale application.

## Development
- Open `index.html` in your browser.
- Data persists in `localStorage` of your browser.
- No backend required.

## Structure
- `index.html`: Marketing page.
- `pos.html`: Main POS interaction.
- `dashboard.html`: Analytics.
- `products.html`: Inventory management.
