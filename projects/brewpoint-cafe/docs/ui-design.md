# BrewPoint Cafe UI Design

## 1. Customer Homepage
- **Purpose**: Brand introduction, featured coffee products, store locations, CTA to order.
- **Layout**: Hero section with background video/image, Bento-grid menu teaser, "Find a Cafe" map widget.
- **Actions**: "Order Now", "Explore Menu".

## 2. Staff Dashboard (Orders Overview)
- **Purpose**: Real-time order tracking and management for cafe staff.
- **Layout**: Sidebar navigation, Top bar (Status indicator), Main content (Order list table).
- **Actions**: "Mark as Complete", "Cancel Order", "View Details".

## 3. Inventory Management
- **Purpose**: Track stock levels and update pricing.
- **Layout**: Data grid with search and filter.
- **Actions**: "Update Stock", "Add New Product", "Delete Item".

## 4. Sales Analytics
- **Purpose**: Visualize daily revenue and top-selling items.
- **Layout**: KPI cards row, Charts (Revenue over time), Table (Top products).
- **Actions**: "Export Report", "Filter by Date Range".
