# UI Design Documentation - Blossom & Bloom Flower Shop

## Overview
A responsive, modern, and premium website for a local flower shop, "Blossom & Bloom". The design focuses on high-quality visuals, a clean aesthetic, and seamless user experience.

## Design System
- **Typography**: Plus Jakarta Sans for headings, Inter for body.
- **Color Palette**: Brand-700 (Deep Forest Green: #064E3B), Brand-100 (Sage Tint: #ECFDF5), Accent-500 (Blossom Pink: #F472B6).
- **Radius**: 20px for hero images, 16px for product cards.
- **Layout**: 1200px max-width container, spacious vertical padding.

## Pages

### 1. Home
- **Purpose**: First impression and quick access to featured products.
- **Layout**: Sticky navbar, hero section with call-to-action, 3-card feature grid, "About Us" snippet.
- **Actions**: "Shop Now" (navigates to Shop), "Learn More" (navigates to About).

### 2. Shop
- **Purpose**: Browse and filter the flower collection.
- **Layout**: Filter sidebar (Categories: Occasions, Plants, Bouquets), 3-column product grid.
- **Fields**: Product name, price, category tag, image.
- **Actions**: "Add to Cart" (visual feedback/toast), filter checkboxes.

### 3. About
- **Purpose**: Showcase the shop's story and floral team.
- **Layout**: Two-column layout (Left: Image of studio, Right: Text narrative). Team cards grid below.
- **Actions**: "Explore Collections" (navigates to Shop).

### 4. Contact
- **Purpose**: Location details and communication channel.
- **Layout**: Split-screen (Left: Contact Info/Map/Hours, Right: Contact Form).
- **Fields**: Name, Email, Subject, Message.
- **Buttons**: "Send Message" (validation, success toast).
