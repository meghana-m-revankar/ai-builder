# Architecture: Dove Marketing Landing Page

1. Page List: Home (index.html)
2. File Structure:
   - docs/index.html
   - docs/css/app.css
   - docs/js/main.js
   - docs/images/
3. Tech Stack: Static HTML + Tailwind CSS (Dark theme, #7c3aed brand, Playful style)
4. Hosting: Static file hosting (GitHub Pages / Vercel)
5. Styling: Tailwind via CDN + custom configuration
6. Interactivity: Vanilla JS for mobile menu and animations
7. Assets: SVG logo and icons
8. Performance: Optimized static delivery
9. Responsive: Mobile-first layout
10. Accessibility: Semantic HTML structure
